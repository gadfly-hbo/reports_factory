# 场景配方：产品发布与路演
> 产品/项目发布、融资路演——讲故事节奏：痛点→方案→证据→愿景，情绪曲线由冷到热

## 页幅与逐页布局配方

**篇幅**：电梯 8-10 页｜标准 12-15 页。

**P1 封面**：深色主色满版；产品名 40pt + 一句话价值主张（副标 18pt accent2）；底部「版本/日期/团队」；中央可放大号 logo 色块（accent1 几何图形，非图片）。
**P2 痛点**：左侧 3 个痛点卡（每卡 = 图标位圆 + 痛点短句 + 量化损失数字 22pt accent1）；右侧一句用户原声引述（大引号 36pt line 色 + 15pt muted 斜体）。
**P3 解决方案**：中央一句话方案（28pt，主色底白字横幅）；下方 3 个「方案→痛点」映射行（左痛点 chip 右解法，中间 rightArrow 形状连接）。
**P4 产品演示**：上半屏「界面示意区」（白底 panel + 灰线框占位 + 标注箭头）；下半屏 3 条功能亮点（编号圆 + 一句话）。
**P5 数据验证**：KPI 卡墙变体——2 大 4 小：大卡（核心指标 34pt bold + 环比 delta）×2，小卡×4；底部口径注释。
**P6 市场机会**：左 TAM/SAM/SOM 同心圆（3 个 ellipse 嵌套 + 右侧标注数字）；右 3 行市场驱动因素。
**P7 竞争格局**：2×2 定位矩阵（横轴性能/纵轴价格，己方 accent1 圆点右上 + 竞品 muted 点）+ 一句差异化结论。
**P8 发展路线**：横向时间线（4 里程碑圆点 + 季度标注 + 每点下 2 行交付物）。
**P9 团队**：左 3-4 张成员卡（姓名 bold + 头衔 muted + 一句背景）；右顾问/合作 logo 色块区。
**P10 愿景与 Ask**：主色满版；一句愿景 30pt 白字；Ask 卡（白底 panel：融资金额/用途拆分 3 行/联系人）。

## 特有组件（代码）

```js
// 定位矩阵点
slide.addShape('ellipse', { x: 8.2, y: 2.1, w: 0.5, h: 0.5, fill: { color: t.accent1 }, line: { color: 'FFFFFF', width: 2 } });
slide.addText('我们', { x: 8.0, y: 2.65, w: 1, h: 0.3, fontSize: 11, color: t.accent1, align: 'center', bold: true });
// 同心圆市场
[[9.0,1.6,3.4,'TAM'],[9.5,2.1,2.4,'SAM'],[10.0,2.6,1.4,'SOM']].forEach(([x,y,d,l]) => {
  slide.addShape('ellipse', { x, y, w: d, h: d, fill: { type: 'none' }, line: { color: t.line, width: 1.5 } });
});
```

**配色建议**：科技深蓝（科技产品）/ 黑金尊贵（高端消费）/ 藏青铁锈（稳健 B2B）。
