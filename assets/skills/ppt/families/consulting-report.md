# 场景配方：咨询与研究报告
> 咨询建议书/行业研究/尽调报告——金字塔原理：结论先行、论据分层、数据密度高

## 页幅与逐页布局配方

**篇幅**：执行摘要版 10-12 页｜完整版 20-30 页（每章 3-5 页）。

**P1 封面**：极简：报告题（2 行 32pt）+ 委托方/日期/密级（muted 小字块右下）；一条 accent1 竖线在左缘（w 0.08in 满高）。
**P2 执行摘要**：核心结论 1 句话（20pt 主色加粗置顶）+ 3-4 条关键发现（每条 = 结论短句 bold + 一行支撑数据）+ 建议一览表（3 列：建议/影响/紧迫度 chip）。
**P3 目录**：章节号大数字 + 章题 + 每章一行要点预告。
**P4 研究方法**：左方法卡（数据来源列表 + 样本量/时间窗数字）+ 右局限性说明（诚实框，line 边框 muted 字）。
**P5+ 章节内页三段式**（每章循环）：
- 章节页：编号 + 章题 + 本章核心论点一句话（52pt→28pt 缩小版）；
- 论据页：左论点（16pt bold）+ 右证据（表格或柱状图，图占 60% 宽）+ 底部「So what」结论条（light 底主色字）；
- 数据页：完整表格（表头主色、行交替、关键列 accent1）+ 口径脚注。
**P 建议路线图**：横轴时间 3 段（速赢 90 天/中期 6 月/长期 12 月），每段 2-3 行动项 + 责任方 chip。
**P 风险与对策**：2 列表（风险 → 缓解措施），高/中/低 chip 色码（accent1/橙/line）。

## 特有组件

```js
// 「So what」结论条
slide.addShape('rect', { x: 0.6, y: 6.3, w: 12.1, h: 0.7, fill: { color: t.light } });
slide.addText('启示：' + soWhat, { x: 0.9, y: 6.38, w: 11.6, h: 0.5, fontSize: 13, color: t.primary, bold: true });
```

**配色建议**：深蓝经典/极简灰白（学术向）；图表一律主色+accent1 双色，禁彩虹。
