# 场景配方：述职与工作汇报
> 个人述职/晋升答辩/试用期总结——成果量化、成长可见、下一步清晰，第一人称

## 页幅与逐页布局配方

**篇幅**：述职 8-10 页｜晋升答辩 12-15 页。

**P1 封面**：姓名 + 岗位/职级 + 周期（「2026 H1 述职」）+ 一句话自我定位（「负责 X，交付 Y」16pt muted）。
**P2 职责全景**：职责地图（中心 = 岗位圆，四周 4-6 职责块 + 各自权重 % chip）；底部团队/协作方一行。
**P3-P5 核心成果**（最重要的 2-3 项，每项 1 页）：STAR 折叠——顶部成果一句话（18pt bold + 结果数字 accent1 22pt）；卡 1 背景/任务（2 行）；卡 2 行动（3-4 条动词句）；卡 3 结果（量化对比表 前→后/目标→实际）；底部「我的独特贡献」1 行。
**P6 数据总览**：个人 KPI 卡墙（4-6 卡：指标/完成值/达成率进度条 rect 填充）。
**P7 亮点与认可**：2-3 个高光时刻（获奖/攻坚/被引用，时间点 + 一行事实）；克制不堆砌。
**P8 不足与反思**：2-3 条真诚不足（每条 = 不足 + 根因一句 + 已采取的动作）——**晋升答辩必页**。
**P9 成长与下一步**：左能力雷达示意（5 维 polygon 线框 + 当前/目标双层）+ 右下周期 3 目标（OKR 式：O + 2 KR）。
**P10 结尾**：一句话承诺 + 「感谢」页（极简）。
