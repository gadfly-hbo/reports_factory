# 场景配方：营销与活动方案
> 营销提案/活动策划/传播方案——有洞察有创意有预算，视觉比商务风更大胆但守色板

## 页幅与逐页布局配方

**篇幅**：提报版 12-15 页。

**P1 封面**： Campaign 名 + 主视觉色块构图（accent1 大几何 + 标题反白，占屏 1/2）+ 提报日期。
**P2 洞察**：一句消费者洞察（22pt 加粗，引号包围）+ 3 行支撑数据；「所以我们的机会是…」结论条。
**P3 目标人群**：人群卡（画像 3 维：人群/场景/动机，各一行式）+ 人群规模数字大卡。
**P4 核心创意**：Big Idea 一句话（26pt 居中，主色底白字横幅）+ 创意阐释 3 行 + KV 示意占位（虚线框 + 「视觉延展位」标注）。
**P5 传播节奏**：三阶段时间线（预热/爆发/长尾，各 = 阶段名 + 平台 chip + 关键动作 + KPI 预估数）。
**P6 媒介组合**：左预算饼图（平台占比，≤5 块）+ 右平台策略表（平台/角色/预算/衡量）。
**P7 内容矩阵**：表：内容类型 × 平台（✓ 标注投放组合）。
**P8-KOL/合作**：金字塔分层（头部 1-腰 3-素人 20，各层预算占比 + 选人标准一行）。
**P9 预算分配**：总预算大数字 + 4-6 行拆分表（行尾占比条：accent1 填充比例 rect）。
**P10 KPI 与排期**：KPI 表（指标/目标值/衡量方式）+ 甘特式排期（3-4 关键节点横条）。
**P11 风险预案**：2 列（风险 → B 计划）。
