# 场景配方：学术与毕业答辩
> 毕业答辩/开题/课题结项——严谨结构：背景→方法→结果→讨论→结论，图表规范、措辞克制

## 页幅与逐页布局配方

**篇幅**：本科答辩 10-12 页｜硕士 15-20 页｜开题 8-10 页（总时长 ÷ 1 分钟/页）。

**P1 封面**：论文题（≤2 行 26pt）+ 学号/姓名/导师/专业/日期（表格化小字块）；校徽位（顶部居中 0.8in 色块占位）；无装饰色条（学术克制）。
**P2 汇报框架**：4-5 章节号 + 章题（不含「创新点」字样的空话）。
**P3 研究背景与问题**：上 2 行领域背景（引文角标 [1]）+ 下研究问题框（RQ1/RQ2 列表，主色左边条）。
**P4 文献综述**：2×2 主题象限（每格 = 主题 + 2-3 代表工作一行式 + 「但缺少…」红字缺口）；底一句定位：「本文填补 …」。
**P5 研究方法**：方法流程图（shape 横向流程 4-6 步）+ 数据集卡（来源/规模/划分）+ 评估指标表（3 列）。
**P6-P9 结果**：每页 1 个实验——主图表占 65%（柱状/折线，误差线注明）+ 关键数字卡（提升 X%，bold accent1）+ 一行发现；基线用 line 灰、本方法用 primary。
**P10 讨论与局限**：左有效发现 2 条；右局限 3 条（诚实，muted）；改进方向 1 行。
**P11 结论与贡献**：3 条贡献（C1/C2/C3 编号）+ 产出清单（论文/代码/专利 chip）。
**P12 致谢**：一句话致谢 + 「请各位老师批评指正」居中 20pt。

## 特有规范
图表必须：轴标签齐全、图例、单位、样本量 n 注明；配色 ≤3 色；表格三线表风格（无竖线，表头下双横线）。

```js
// 三线表：仅横向分隔
rows.forEach((r, i) => slide.addShape('line', { x: 0.8, y: 2.4 + i * 0.42, w: 11.7, h: 0, line: { color: t.line, width: i === 0 ? 2 : 0.75 } }));
```

**配色建议**：极简灰白/深蓝经典；**禁** emoji、感叹号、营销词（「革命性/极大」）。
