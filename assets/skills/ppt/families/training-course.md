# 场景配方：教学与培训课件
> 内训/公开课/知识分享——大字号少文字、一页一概念、示例先行、有练习有总结

## 页幅与逐页布局配方

**篇幅**：按课时，每 10 分钟 1-1.5 页；60 分钟课 ≈ 8-10 页正片 + 练习页。

**P1 封面**：课程名 36pt + 一句话收获承诺（「学完你将能…」18pt accent1）+ 讲师/时长 chip。
**P2 学习目标**：3-4 条「能做 X」句式（动词开头，每条 = 编号圆 + 18pt 短句）；底部议程时间线。
**P3+ 知识页三件套**（每个知识点循环 2-3 页）：
- 概念页：术语 32pt 居中 + 一句话定义（20pt，最多 2 行）+ 一个生活化类比卡（浅底 panel）；
- 示例页：「对 vs 错」双栏（左 ✓ 正例 accent 绿边、右 ✗ 反例 line 灰边，各 2-3 行）；
- 图解页：流程/结构用 shape 搭（箭头连接 3-5 节点，每节点 = 圆 + 词），**不用大段文字**。
**P 练习页**：任务卡（题目 + 提示折叠 + 计时 chip「讨论 5 分钟」）；留白 ≥40%。
**P 常见坑**：3 个误区卡（accent1 实心小三角图标位 + 误区 + 一句纠正）。
**P 总结页**：本课 3 个 takeaway（复述学习目标句式）+ 下节预告 + QR/资料位（色块占位）。

**字号下限 16pt**（学员远距可读）；每页文字 ≤60 字；配色建议深绿森林/科技深蓝。
