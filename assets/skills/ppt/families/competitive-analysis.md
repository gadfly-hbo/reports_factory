# 场景配方：竞品与市场分析
> 竞品分析/市场扫描/进入评估——矩阵与证据并重，结论敢下但标置信度

## 页幅与逐页布局配方

**篇幅**：速览版 8-10 页｜深评版 15-20 页。

**P1 封面**：分析主题 + 覆盖竞品数/数据窗口（「5 家竞品 · 2026 Q1-Q3」chip 行）。
**P2 市场格局**：左市场规模时间序列（柱状 3-4 期 + CAGR 标注）+ 右格局类型判定卡（集中/分散 + 一句依据）。
**P3 竞品选择**：入选/排除清单表（各家 + 一行入选理由/排除原因）；**不回避排除逻辑**。
**P4 对标总览矩阵**：核心页——功能/性能矩阵表（行 = 维度 6-10，列 = 我方+4 竞品；✓/部分/✗ 三态，我方列 accent1 描边）；底部 3 条速读结论。
**P5+ 逐家速写**（每家半页-1 页）：定位一句话 + 定价卡 + 3 优势/3 弱势（绿/灰双色列）+ 最近动向时间点。
**P7 SWOT**：四象限（我方）：S/W/O/T 各 3 条（O 与 T 须引用外部数据来源角标）。
**P8 用户口碑**：好评/差评词云式列表（各 5-6 短语，频次数字 chip）+ 数据来源（评论数/平台）。
**P9 机会点**：2-3 个机会卡（每个 = 洞察 + 依据数据 + 可进入性评级 高/中/低 + 置信度标注「证据强/中/弱」）。
**P10 建议行动**：行动表（动作/窗口/依赖/预期收益）+ 下一步监测指标。

**证据纪律**：每个竞品论断标来源（官网/财报/实测/评论）与日期；无来源的判断必须标「推断」；配色建议深蓝经典/藏青铁锈。
