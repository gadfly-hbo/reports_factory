# M2 真实使用反馈记录模板

> M2 阶段门（"多次实际使用可重复完成"）需要真实使用数据。本模板用于每次真实任务使用后的登记。
> 指标口径来自产品方案 v1.0 §15。**不预设提升比例；基线先行。**

## 每次使用登记

| 字段 | 填写 |
|---|---|
| 日期 | |
| 任务 | （如：月度经营复盘汇报） |
| 使用者角色 | |
| 到首份可用初稿的时间 | 从材料就绪到"可继续编辑的初稿"的分钟数 |
| 到正式定稿的时间 | 从导入到确认可上会的分钟数（含人工核验） |
| 返工量 | 重做页数 / 实质内容修改次数 / 是否整稿重新生成 |
| 阻断问题数 | 导出前检查发现的阻断项数量（数字矛盾/缺失/排版/权限） |
| 关键来源覆盖 | 关键陈述中有来源或计算依据的比例（%） |
| 导出可用 | PPTX/PDF 在目标软件（PowerPoint/WPS/Keynote，注明版本）能否正常编辑使用 |
| 是否会再用 | 下次同类任务是否继续用本工具（是/否/不确定 + 原因） |
| 遇到的优先级最高的问题 | |

## 指标汇总口径（v1.0 §15）

| 指标 | 统计方式 |
|---|---|
| 到首份可用初稿的时间 | 上表登记的中位数，与同类任务旧流程对比 |
| 返工量 | 重做页数 ÷ 总页数；整稿重生成次数单独计 |
| 阻断问题数量 | 每次导出的阻断项计数 |
| 导出可用率 | 可用导出 ÷ 导出总数，按格式 × 软件环境分列 |
| 重复使用 | 第二次真实任务是否继续采用（这是独立产品价值的核心信号） |
| 无关变更率 | 局部编辑引发的范围外变化数量（应趋近于 0；diff 视图可辅助核对） |

## 观察到的增长假设（只观察、不承诺）

- 会议材料被转发的次数与去向
- 管理者是否主动要求"下次也用这种方式"
- 是否有非登记用户自发试用
