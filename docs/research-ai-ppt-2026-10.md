# 外部产品调研：AI PPT 生成（Kimi / ChatGPT / Gemini / Gamma / 中国系）

> 调研日期：2026-10-06。目的：验证「给材料直接出 PPT」的行业标准体验，为 Report Studio 下一轮简化重构定抄什么、留什么。
> 方法：三个并行调研组（中国系 / OpenAI / Google+Gamma），官方页面优先、第三方实测佐证，未查证项逐一标注。

## 一句话结论

**「给材料 → 直接出完整 PPT」在 2026 年已是成熟标准体验**（大纲可改 → 一键生成 → 30 秒~几分钟出整套），而「只能一次性生成」的说法**对头部产品已过时但半对**：单页级 AI 修改已普及（但多为对话式而非显式按钮），**导出后断链**（AI 编辑能力不随 pptx 走）和**无内容审批**才是全行业真空——后者正是我们的差异化空间。

## 各产品速览

| 产品 | 输入 | 流程 | 输出 | 单页修改 | 审批 |
|---|---|---|---|---|---|
| **Kimi Slides** | 文本/文档/图片/PPT 模板（长材料强项） | 描述→大纲（可改）→生成→编辑，约 30 秒~分钟级 | 在线画布 + 导出**原生可编辑 pptx**/PNG | 对话式+批注定点改，每轮自动存版本可回退 | 无 |
| **WPS AIPPT** | 一句话/长文本/文档 | 解析→问目标→大纲（逐页可改）→生成，约 30 秒 | 原生 WPS 演示（pptx 生态） | **单页重新生成/单页换版式（证据最硬）**+逐页配图替换 | 无 |
| **ChatGPT** | 杂料（agent 自查资料）/文件/模板 | Agent 模式交付成品；无强制大纲门；**慢（十几~几十分钟）** | 原生 .pptx / Google Slides / PowerPoint 加载项 | 加载项支持"只改指定页"；纯聊天路径"改一页变重写全本"是著名痛点 | 仅安全确认，非内容审核 |
| **Gemini（Slides 内）** | prompt + Drive 文件 + 风格参照 deck | presentation plan（可改）→ Approve → 生成，几分钟 | **完全原生 Google Slides** | "Generate a slide" 可 **Replace 当前选中页**（官方单页重生成） | 无 |
| **Gamma** | 粘贴文本/上传 pptx/docx/PDF/URL | 大纲（可改）→主题→生成，几十秒 | 在线卡片画布；导出 pptx **有损**（block→textbox） | **per-card AI edit 标杆**：每卡一个 AI 入口+改图+即时生效 | 无（分享/评论有） |
| 通义/百度/讯飞 | 文档/链接/图片（百度输入最杂食） | 大纲可改→选模式→生成 | 导出 pptx | 大纲级重生成+手动改；单页 AI 重生成证据不足 | 无 |

## 对用户判断的验证

1. **「他们只能一次性生成」**——半对。逐页 AI 修改已是标配，但形态分三档：
   - 显式按钮级：WPS（单页重生成/换版式）、Gemini（Replace 当前页）、Gamma（per-card edit）——三家；
   - 对话/批注式：Kimi（批注定点修改+版本回退）；
   - 基本没有：ChatGPT 纯聊天路径（改一页重写全本）、通义/百度/讯飞。
   - 且**所有产品在导出 pptx 后 AI 编辑能力全部断链**，字体丢失/偏移是通病——"一次性"的体感主要来自这里。
2. **「我们做逐页改 + 审批」**——方向被调研证实：
   - 单页重生成我们有（M6 S6 rewrite_page + 数字护栏），能力对齐 WPS/Gemini 档；
   - **内容审批工作流全行业真空**（ChatGPT 的 approval 是操作安全确认，不是内容审核签批；Gamma 只有分享评论）——我们的 G1 签批 + 内用/外发两级审批是独家差异化。

## M6「重构失败」的根因定位（结合调研反推）

行业标准是「材料进 → **内容完整、排版成型的成稿**出」；我们 M6 的"一键生成"是**确定性组装**（AI 是可选旁路），产出的是骨架式 deck（材料标记不足时大量"待补充"页）——流程压对了，**产物的完整度和成品感不对**。简言之：输给的不是交互步数，是生成质量与即时感。

## 下一轮重构建议（抄什么、留什么）

**抄（对齐行业标准主路径）：**
1. **LLM 进默认生成路径**：材料 → LLM 逐页起草完整内容（headline/bullets/正文，绑定材料来源）→ 排版成型，一次性出整套；确定性规则降级为校验/兜底（保留不编造约束与围栏）。这是消除"待补充页"体感的关键。
2. **主路径三步化**：生成页（上传/粘贴材料 + 选模版风格 + 一个生成按钮）→ 逐页编辑画布 → 审批导出。五阶段壳层降级为高级入口（M6 遗留缺口，一并补）。
3. **大纲确认可选化**：Kimi/Gemini 都有可改大纲环节但非强制——我们默认直出，提供"先看大纲再生成"开关。
4. 模板库补**品牌/风格预设**（M6 缺口：模版 brand 预设未实现），对齐 Gamma theme/Kimi 风格选择。

**留（差异化，不抄掉）：**
1. **逐页编辑 + 单页 LLM 重生成**（已有，只需在新主路径里前置）；
2. **审批工作流**（G1/内外导出）——全行业没有，是我们对"报告可信交付"场景的立足点；
3. 围栏资产（出站白名单/批准持久化/预算三线/审计）——AGENTS.md 标准要求，不动。

**代价与前提（需决策）：**默认路径 LLM 化意味着每次生成烧 token（预算三线已有兜底）、无密钥时回退确定性骨架（兜底已有）。生成质量依赖 minimax/mimo 的中文长材料表现（M5 probe 已验证 schema 遵从，内容质量未盲评）。
