# look_page 视觉自检效果验证（B2 实验，2026-10-13）

痛点 #6（版式不稳定/溢出）· flow-13 · 单次盲测实验，方向性证据（样本 8 页，非统计显著）。

## 方法学

- **夹具**：8 个生产同构 HTML 预览页（1280×720，agent 预览同形态），缺陷由构造保证：
  - 坏-明显：`bad-overflow`（footer 盒子定位出界、底缘 860px 被 720px 画布裁切）、`bad-contrast`（#ECEEF1 字 on #F7F8FA 底）
  - 坏-中等：`bad-crowded`（11px 密排文字墙）、`bad-occlusion`（文字压斜纹渐变繁忙区）
  - 好：`good-cover` / `good-text` / `good-chart` / `good-image-text` 四型各异
- **管线**：与生产 look_page 完全一致——`shootHtmlJpeg`（1280×720 JPEG q80）→ 主链 `minimax-cn/MiniMax-M3` transport 带图真调。
- **提示词**：镜像 skill 检查单原文（文字遮挡、溢出边界、对齐、留白失衡、字号过小）+ 结构化裁决 `VERDICT: GOOD|BAD`。
- **稳定性**：好页预探翻转 1 次（good-chart GOOD/BAD）→ 全量每页 ×2 取多数。
- 复跑：`npm run build && node scripts/probe-look-page.mjs`（真调不进 CI；`--dry` 只验截图管线）。

## 结果（每页 ×2 取多数）

| 夹具 | 期望 | 裁决 | 稳定性 | 模型主要理由（摘） |
|---|---|---|---|---|
| bad-contrast | BAD | **BAD** | BAD/BAD 一致 | 对比度严重不足几乎难辨 + 留白失衡 |
| bad-crowded | BAD | **BAD** | BAD/BAD 一致 | 字号过小 + 文字墙密度过高 + 层级扁平 |
| bad-occlusion | BAD | **BAD** | BAD/BAD 一致 | 斜纹区对比度弱 + 标题断行阅读断裂 |
| bad-overflow | BAD | **BAD** | BAD/BAD 一致 | 留白失衡 + 页脚浅灰小字（裁切区被感知为可读性问题） |
| good-chart | GOOD | **GOOD** | GOOD/GOOD（预探曾翻转 1 次） | 布局整齐、配色协调、标签清晰 |
| good-text | GOOD | **GOOD** | GOOD/GOOD 一致 | 左对齐一致、层级合理 |
| good-image-text | GOOD | **INCONCLUSIVE** | GOOD/BAD 分裂 | GOOD 侧：分区清晰无遮挡；BAD 侧未达多数 |
| good-cover | GOOD | **BAD（误报）** | BAD/BAD 一致 | 「右侧约 60% 空白，留白失衡」——封面型留白被判缺陷 |

## 评分与决策

**召回 4/4（100%）· 误报 1/4 · inconclusive 1/8** → 按实验前定死规则落入**中间态**：机制有效但需校准。

- **召回面（强）**：四类缺陷全部抓出且 ×2 全一致——「模型看图抓排版事故」的能力成立，机制赌注兑现。
- **误报面（弱）**：误报与分裂全部集中在「留白」维度，且都指向稀疏布局（封面/图文页）——模型对留白的评判标准严于人类对 PPT 封面的惯例（封面留白是设计而非缺陷）。注：good-cover 夹具为左对齐大留白形态，真实 agent 封面多为居中构图，误报率可能被夹具形态放大——读数时打折。
- **归因偏差（记档）**：bad-overflow 的构造缺陷是出界裁切，模型感知为「页脚可读性/留白」问题——检出差，归因偶偏（对自纠循环无碍：改代码重渲即可）。

## 结论与建议

1. **产品叙事可升级（有条件）**：检出差的全量表现支撑「视觉自检有实测依据」，但正式把卖点从「机制」升级为「效果」建议绑定「页型容忍度校准后复跑、误报归零」再定稿——本实验的误报面（封面留白误判）尚未校准。
2. **校准方向（后续 flow，不属本实验范围）**：skill 检查单或 look_page 提示区分页型容忍度——封面/章节页允许大留白；「留白失衡」评判应以内容页为限。
3. **预检兜底不触发**：召回远高于 2/4 阈值，程序化 layout_budget 预检按决策规则跳过（规则级边界：遮挡/对比本就不可规则检出，模型级已覆盖）。
4. **换模型时复跑**本实验（脚本+夹具已进仓）。

## 局限

- 单次实验、8 页样本、×2 多数——方向性证据，非统计显著。
- 直调上界估计：生产中 look_page 发生在 agent 长会话循环内，上下文压力下表现 ≤ 本实验（K4 永久记档）。
- 误报率受夹具形态影响（good-cover 左对齐大留白非典型封面构图）。
- 好页/坏页二值裁决不含「轻微问题」中间档——真实使用中 agent 收到的是问题清单而非二值。
