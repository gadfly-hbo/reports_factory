# Proposal：成果视图页级修改 composer（flow-4，用户反馈迭代①）

来源：2026-10-11 用户试用反馈 + 截图。现状痛点：成果视图选中页后，提示文案「切换到『对话』视图修改这一页」——修改动作被迫跨视图。

## 交付（W5 增补）
成果视图选中页时，大图预览下方内嵌**页级 composer**：页标记徽标（第 N 页 · 标题）+ 输入框 + 发送/插话（与主 composer 同一 send 语义：空闲=发送开新轮，busy=插话）+ 停止；busy 时内联显示等待态与工具卡（真实 SSE）；轮次结束后**留在成果视图**，预览自动刷新，并在内嵌区显示最近一轮回复摘要（可折叠查看全文于对话视图）。
不变：对话视图 composer（含附件）不動；词条/DESIGN token/真实状态规则不变。
合同增补记录进 ui-contract.md §5。
