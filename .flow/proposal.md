## 1. M3 工程范围（候选切片，按依赖排序）

### 1.1 长报告（分析／研究报告）——核心交付

- **新交付物类型**：ReportBrief 增 `deliverable_type`（meeting_deck / research_report）；研究报告走"问题 → 口径 → 方法 → 发现 → 证据 → 限制 → 建议"文档主线（§4.1），非幻灯片切页。
- **DOCX 渲染适配器**：与 PPTX/PDF 同一 ReportSpec 驱动；标题/正文/表格原生可编辑；来源脚注保留。
- **独立分发 HTML**：把应用内预览升级为可单文件分发的自包含产物（§4.2 首期排除项，M3 回收）。
- **可信边界不降**：质量检查引擎对研究报告同样生效；数字一致性/来源引用/不确定性保留全部复用。

### 1.2 一页决策摘要（独立形态）

- 从同一资产集派生单页摘要：问题 → 选择 → 建议 → 风险 → 需要谁决定（§4.1）。
- 输出 PPTX 单页 + PDF 单页 + HTML；不与长报告互相矛盾（§4.1"不能在不同文件中生成互相矛盾的数字"→ 一致性校验覆盖新产物）。

### 1.3 DOCX 导入（更多输入）

- mammoth 解析（docx → 结构化内容），复用 markdown 的主张/证据通道；宏/脚本不执行（§12.2）。

### 1.4 品牌模板（有限制的企业模板能力）

- **不做**任意模板导入设计器（§3.2 排除项维持）；做**受控品牌配置**：主题色板 + Logo 图片 + 字体名，进 theme token；导出产物带品牌标识。
- v1.0 §4.2"支持有限主题配色"的扩展，不越界到"任意企业模板导入"。

## 2. 本轮不做（边界）

- M4 集成（JuanerAI 适配器）；M2 真实使用采样（留给用户，模板已交）。
- 任意布局幻灯片设计器、模板市场、多人协作（§3.2 永久排除项）。
- PPTX 品牌模板的深度母版编辑——只做 token 级（色/Logo/字体名）。

## 3. 继承约束（不因 M3 放松）

- M3 门禁："不降低现有会议汇报质量与可信边界"——回归 golden + 全部测试必须全绿且零漂移；新增格式全部过同一检查引擎。
- 可信规则不回退：推断不升级、冲突不静默、阻断清零才正式定稿、冻结快照、缺数据不伪造、隐私导出门禁。
- 新格式输出沿用隐私导出链（external 检查/降级/元数据中性化）。
