# Proposal：PPT 场景家族系统（flow-7）

来源：2026-10-13 用户反馈「PPT 比较单一，要能生成各种类型和场合」。

## 设计
- **核心 skill 瘦身**：SKILL.md 保留红线/工作流/设计系统（6 色板）/图片规范/视觉自检/deck 工件组织/自检清单；§四逐页配方迁出为家族文件之一。
- **场景家族**：`assets/skills/ppt/families/<id>.md`，每家族 = 页序骨架 + 每页元素级配方 + 特有组件代码 + 配色建议映射。首发 9 家族：通用商务汇报（默认）/产品发布路演/咨询研究报告/教学培训课件/学术毕业答辩/营销活动方案/技术架构评审/述职工作汇报/竞品市场分析。
- **宿主注入**（agent 读不到仓内文件，工具根限项目目录）：send() 组 system = BUILD_SYSTEM + 当前项目家族配方（project.json 新增可选 ppt_family 字段；未设/缺失→默认家族，降级不阻断）。每 run 只带 1 个家族，上下文不膨胀。
- **API/UI**：GET /api/ppt/families；PUT /api/projects/:id/family；新建对话框加「场景」选择（默认自动=通用商务）；header 显示场景徽章 + 可切换（下一轮生效）。
- 新增家族 = 放一个 .md 文件，零代码。

## 验收轴
1. 家族注册表 ≥9 且可解析名称/描述；坏文件降级不阻断
2. 宿主缝：pin 家族后合成 transport 收到的 system 含该家族「场景配方」标记；未 pin 含默认家族
3. API：PUT 持久化（重启可读）、非法 id 400
4. UI：新建可选场景、header 徽章可切换并持久化（smoke）
5. SKILL.md 瘦身后红线/自检/组件配方仍在（文本断言）
