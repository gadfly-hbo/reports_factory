## 1. M2 工程范围（本轮 flow 的候选切片）

### 1.1 导出隐私检查（v1.0 §12.2"对外导出"行——已识别的真实规格缺口）

- 对外导出（exportScope=external）前检查：隐藏页面、备注、附录、元数据、图表底层数据是否含敏感内容。
- 可编辑图表含底层数据：对外分享提供**"保留可编辑数据"与"只分享必要聚合结果"的明确选择**；安全优先于可编辑性（§12.2 原文）。
- 文档元数据清理（PPTX/PDF 的 author、title、公司等属性）。
- §12.3：外部版本按授权保留必要口径；**不能因隐藏敏感信息而产生虚假来源**。
- 对应 §13.3 质量门槛的后半句（"对外分享设置覆盖备注、隐藏内容与图表内嵌数据"）——目前未实现、未验证。

### 1.2 版本比较（v1.0 §5.3 + M2 交付"版本比较"）

- 修订 diff API：任意两个 ReportRevision 的结构化差异（页增删/重排、标题/正文/要点/表格单元变更、指标数值变更、claim 绑定变更）。
- §5.3 原文："系统显示修改前后差异。数字和结论引用发生变化时，重新触发对应检查。"
- UI：版本比较视图（修订列表 → 选两个版本 → 差异展示）。

### 1.3 标准轴重构窗口（review-findings.md 留档的非阻断项，M2 为指定窗口）

- 删除死代码（gateway TEMPLATE、exportGate 的 void spec、theme claimKindVisual）。
- workspace 磁盘布局知识收进 WorkspaceStore（四模块泄漏 → 单一出口）。
- 去重：渲染页脚规则、storage 的 readdir→parse 循环、空 IngestResult 字面量、edit 的 updatePage。
- 类型化边界：API 请求体 zod 校验、open_questions 结构化（UI 不再子串匹配"冲突"）、pageTypeLabels 用 Record<PageType, string>。
- 约束：**纯重构，行为不变**，68 项测试 + 冒烟保持全绿（现有测试即安全网）。

### 1.4 回归样例集（M2 交付"回归样例"）

- `npm run regression`：全部测试 + 零售样例再生成 + 三格式一致性 + 可编辑性断言 + 关键文本 golden 比对，一条命令完成。
- 作为 M2 验收与后续 M3 的回归基线。

### 1.5 XLSX 导入（A1 批准延后项的回收，候选）

- 简单 XLSX：工作表选择、列口径登记、不执行宏（§4.2 表格限制）。
- 预算不足时首先砍（沿用 A1 精神）。

## 2. 本轮不做（边界）

- **真实用户反馈记录**：需要真实使用者，无法在本轮工程内完成；交付一个反馈记录模板与指标口径（§15 的返工量/重复使用/无关变更率如何登记），采样本身留给用户。
- 外部模型实际接入（仍按 A3 仅接口+门禁）；M3 范围（长报告、一页摘要独立形态、品牌模板、DOCX）；M4 集成（JuanerAI 适配器）。
- 失败恢复：重启恢复与从失败步骤重试已在 M1 实现并测试（e2e 两行），无新增工程，仅在回归样例中保持覆盖。

## 3. 继承约束（不因 M2 放松）

- 全部 v1.0 边界与三条不可混淆界线；本地优先；模块化单体；不预建重设施。
- 可信规则不回退：推断不升级、冲突不静默、阻断未清零禁正式定稿、冻结快照、缺数据不伪造。
- 重构切片不改行为；新功能照旧 TDD（RED → GREEN）。
