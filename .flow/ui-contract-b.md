# M10-B UI Contract：生成节点工具 Agent 化 + 编辑节点可视化

> 依据：proposal.md（D2 六步）+ prd-b.md（工具 Agent + 可视化）。视觉基线：DESIGN.md v4.2。

## Surfaces 变化

### S6 生成（第 4 步）——交互升级

**新增：工具 Agent 过程可视化**
- 每页生成时显示**实时过程**（非只显示状态）：
  - "正在写代码…"（write_code 调用时）
  - "正在渲染…"（run_render 调用时）
  - "渲染失败，正在自纠…"（stderr 非空时）
  - "渲染成功"（退出码 0 + PPTX 有效）
- 过程日志折叠面板（点击展开看每轮工具调用详情：轮次/工具/耗时/结果摘要）
- 预算进度条："轮次 3/10 · 工具调用 5/20 · 耗时 2:30/10:00"

**状态徽标扩展**：
- `排队中` / `生成中（工具 Agent）` / `渲染成功` / `渲染失败（预算耗尽）` / `渲染失败（模型错误）`

**失败态交互**：
- 预算耗尽：提示"该页生成预算耗尽（10轮/20次调用），已用框架标题占位。可重试或手工编辑。"
- 模型错误：提示"模型连续错误，已用框架标题占位。可重试。"

### S7 逐页编辑（第 5 步）——新增可视化

**布局改造**（三栏）：
- 左：页列表（不变）
- 中：编辑器（不变：手工直改 + agent 改写指令）
- **右：页预览图**（新增）——当前选中页的 PPTX 渲染截图（PNG）

**预览交互**：
- 选中页 → 右侧加载该页预览图（loading 态："渲染预览中…"）
- 手工修改文字字段 → 失焦后自动重新渲染预览（防抖 500ms）
- agent 改写成功 → 自动重新渲染预览
- 预览图下方标注："预览为近似渲染（HTML 截图），实际以导出 PPTX 为准"

**编辑范围不变**：纯文字字段（headline/bullets/table_note）+ agent 改写（单发）

## Click paths 变化

**生成页（S6）**：
- 主：点"开始生成"→ 逐页工具 Agent 循环（实时显示过程）→ 全部完成 → "进入逐页编辑"
- 失败：某页预算耗尽 → 该页标"失败（预算）"→ 可点"重试该页"（重新给预算）或"手工编辑"（跳到编辑页）

**编辑页（S7）**：
- 主：选页 → 右侧显示预览 → 改文字 → 预览自动更新 → 保存
- 新增：agent 改写 → 成功后预览自动更新

## Negative cases

- 预览渲染失败：显示"预览渲染失败（不影响实际 PPTX）"占位图
- 工具 Agent 调用白名单外工具：前端不显示细节（后端拒绝+审计），只显示"模型尝试越界操作已拦截"
- 预算进度条超 80%：变 warn 色提示

## Terminology

- "工具 Agent"（用户可见，解释生成方式）
- "渲染预览"（编辑节点预览图）
- 禁用词：无新增
