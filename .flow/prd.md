## Problem Statement

M6 交付的「一键生成」走确定性组装，产出骨架式 deck（材料标记不足时大量「待补充」页），与行业标准（Kimi/Gemini/Gamma/WPS：材料进→内容完整的成品出）相去甚远，用户判定重构失败。产物完整度/成品感是根因，不是流程步数。

## Solution

1. **LLM 进默认生成路径**：材料 → 按模版 page_plan 确定性定结构 → **LLM 逐页起草完整内容**（headline/bullets/body，grounded 于材料、数字护栏强制）→ 与确定性表格/图表合成 → 成品稿。无密钥/模型不可用/预算超帽 → 回退确定性骨架并明示。
2. **主路径三步化**：生成页（材料+模版+受众用途+生成按钮+进度）→ 逐页编辑 → 审批导出；五阶段壳层降级为高级入口（不删除）。
3. **大纲确认可选**：默认直出；开关打开时起草前停下展示结构+主旨，确认后继续。
4. **模板 brand 预设**：三模版各带品牌风格预设，生成即应用；用户自定义 brand 覆盖之。

## User Stories

1. 作为报告生产者，我想上传/粘贴材料后点一次「生成」就得到内容完整的成稿，以便像 Kimi 一样材料进成品出。
2. 作为报告生产者，我想让每页的文字内容来自我的材料（LLM 起草）而非「待补充」占位，以便成稿即成品。
3. 作为报告生产者，我想让生成内容里的数字必须来自材料（编造被拒），以便 LLM 成品可信。
4. 作为报告生产者，我想让材料不足的地方明示「材料未覆盖」而不是编造，以便不实内容不进报告。
5. 作为报告生产者，我想在无密钥/模型故障/预算超帽时自动回退规则版骨架并明示，以便主线永不阻塞。
6. 作为报告生产者，我想默认直接出整套，也可打开「先确认大纲」开关看过结构再生成，以便不同信任度下使用。
7. 作为报告生产者，我想在三步主路径（生成→编辑→审批导出）里完成全流程，以便不用理解五阶段。
8. 作为报告生产者，我想让五阶段与采证/冲突/口径收进「高级」入口保留可用，以便精细控制时不丢能力。
9. 作为报告生产者，我想让每个模版自带品牌风格（色板/字体），生成即有风格，以便成品不素。
10. 作为报告生产者，我想自定义品牌后覆盖模版预设，以便保持企业 VI。
11. 作为报告生产者，我想生成过程可见（当前第几页/已用调用数/预算余量），以便看得懂过程。
12. 作为报告生产者，我想生成中途失败可续跑（只重跑失败页），以便不整副重来。
13. 作为报告生产者，我想生成调用过出站批准（首次预览发送范围）与预算门，以便围栏不因自动化松动。
14. 作为报告生产者，我想敏感来源内容默认不出站也不进 LLM 起草，以便隐私分级在默认路径生效。
15. 作为报告生产者，我想生成后单页直改/LLM 重生成/结构操作照旧可用，以便逐页精修（M6 能力前置到主路径）。
16. 作为报告生产者，我想审批导出（体检/G1/内外）仍在第三步显式把关，以便可信交付的差异化保留。
17. 作为报告生产者，我想生成调用计量与成本进审计流（零内容），以便可回放可追责。
18. 作为测试维护者，我想起草路径有 record→replay 夹具，以便离线回归（P6）。
19. 作为测试维护者，我想护栏/回退/预算/批准的负例测试，以便围栏不被削弱。
20. 作为测试维护者，我想壳层改造有入口存在性断言与视觉验收，以便不再出现「声明与代码不符」。

## Implementation Decisions

### D1 生成管线（改造 workbench.generate）

- 结构仍由模版 page_plan 确定性投影（M6 已交付，保证页型正确）；新增**起草阶段**：按页串行 LLM 起草（每页一次单发 completion，调用形态 GRILL G1）。
- 管线阶段序列：`outline`（确定性结构）→ `draft`（逐页 LLM 起草，新增）→ `assemble`（合成渲染）→ `checks`。checkpoint 断点续跑扩展：逐页粒度（失败只重跑该页）。
- 每页起草 = 一次 `LlmStageClient.complete` + zod 强校验；禁 tool-call 循环（KA-5）。
- 逐页调用数 = 页数（≤ page_budget），生成前预估并在进度中明示；预算三线兜底（默认 50 次/30 分钟/单阶段 20 轮）。

### D2 起草护栏（红队 KA-2 硬约束）

- **zod schema**：每页产出 `{ headline, bullets: [{text, claim_ref?}], body? }`（与 rewrite_page 同形）。
- **数字护栏**：起草内容中的每个数字必须存在于材料派生文本（claims/tables/notes 摘要）中；违反整页拒绝并回退该页为确定性占位（明示）。与 rewrite_page 的 digitGuard 同源复用。
- **来源绑定**：bullet claim_ref 必须在页面 claim_refs 白名单内（沿用 M6 校验）。
- **不编造约束**：材料未覆盖该页型时，起草提示词要求返回 `uncovered: true`，产物落「材料未覆盖」明示占位而非编造。
- **表格/图表/口径注**仍由确定性组装产生，LLM 不产数字表格。

### D3 合成与出站

- 起草产出经白名单过滤（claim_ref 白名单）后替换 outline 草案的 headline/bullets/body，进既有 assemble（确定性合成表格/图表/必要边界注入零改动）。
- 起草调用走 authorized-summary 出站：首次预览明示发送范围（材料派生摘要）、sensitive 来源排除、批准持久化、预算门、零内容审计（事件含 draft 阶段）。

### D4 回退

- 无密钥 / 模型不可用（ModelUnavailableError）/ 单页起草反复失败（schema+护栏 2 次）→ 该页回退确定性占位，整体不阻塞；全部页回退时明示「已用规则版」。

### D5 主路径三步化 UI（红队 KA-4：入口存在性断言 + 视觉验收）

- 新路由 `/project/:id/generate`（生成页）：材料清单摘要、模版与风格选择（brand 预设预览）、受众/用途、大纲确认开关、「生成」按钮、逐页进度（第 N/M 页 + 调用计数）、回退/停点明示。
- 编辑步 = 现组装视图能力（单页直改/LLM 重生成/结构操作，M6 已有）在主路径第二步入口直达。
- 审批导出 = 现检查/导出能力在第三步整合入口（体检卡 + G1 + 内外导出）。
- 侧栏重组：主路径 `01 生成 / 02 编辑 / 03 审批导出` + 「高级」折叠组（材料/编审/组装/检查/导出原五项）；命令面板同步。**只重组入口不删视图**。

### D6 brand 预设

- `TemplateConfigSchema` 加 `brand: BrandConfigSchema`；首批三模版各配一套风格（GRILL G4：复盘=铁橘 #b44626/#8f3820、执行摘要=深藏青 #263442/#b44626、研究报告=墨青 #1f3a3d/#b44626）。
- 应用优先级：project.brand 显式设置 > 模版预设 > DEFAULT_BRAND。

### D7 大纲确认开关

- 生成页 checkbox（默认关，会话内一次性）；开启时管线完成 outline 后暂停，展示页型序列+各页主旨（可改 headline），确认后继续起草。

### D8 seam

- 复用：`modelClient()` replay/真实切换点、workbench 服务层、generate 服务边界（M6）。
- 新增：起草函数（`src/model/ai-draft.ts`）边界——replay 夹具精确构造 transport 键（同 ai-page 模式）。

## Testing Decisions

- 好测试标准：断言外部行为（生成产物/护栏拒绝/回退明示/断点续跑/入口存在），不 mock 内部协作。
- 负例必测：编造数字拒绝、越权 claim_ref 拒绝、材料不足 uncovered 占位、无密钥回退明示、预算超帽停点、批准未给 403、敏感来源排除。
- replay：起草调用 record→replay（合成 fixture，禁真实数据录制纪律不变）。
- 壳层：路由/入口存在性断言（rg 可验证）+ 视觉验收（视觉门）。
- 回归：211 既有测试零破坏（回退路径=现有确定性管线行为）。

## Out of Scope

- 渲染美感/模板美化大改（KA-1 若指向渲染层，单独立项）。
- 图片编辑（S7 仍后置）、协作/多人、tool-call agent、模板导入设计器。
- 流式逐页渲染到 UI（进度条足够，逐页完成后可看）。
