## 目标

以 **JuanerAI 系统蓝图 v4.2**（`juanerai-system-blueprint-v4.2.html`，今日 MacBook 生成，已拷到本机 `/tmp/blueprint-v42.html`）为权威基准，对工作台做第三轮 UI 优化——采用它的视觉语言与组件模式。

## 蓝图与现版的关键差异（将采纳）

| 维度 | 蓝图 v4.2 | 现版 |
|---|---|---|
| accent | **#b44626 铁锈橘**（更沉稳） | #e8643a 亮橘 |
| eyebrow | **accent 色** 12px/650/0.1em | 灰色 10px |
| 导航选中 | **accent-soft 底 + accent 字 + 650**，带 mono 编号 | 白卡描边 |
| 按钮 hover | **accent 描边 + accent-soft 底** | surface-2 底 |
| 分段控件 | soft 底容器 + 白底活动段 | 独立 pill |
| 原则横条 | **深藏青 band + 白描边 chips**（"有据、不越界、可检查，并不等于让用户逐个批准每步"） | 无 |
| 圆角/标题 | radius 12；标题 650 字重 -0.025em 字距 | 14px / 600 |

## 改动方案

1. **Token 值切换**（`styles.css :root`，结构不动）: accent→`#b44626`、strong→`#8f3820`（推导）、soft→`#fcf0e9`、line→推导 `#ecd7cb`；text→`#242830`/`#626773`/`#8e939d`；border→`#dedcd6`；soft→`#f0efeb`；radius→12；浮层阴影→`0 18px 60px rgba(25,38,49,.14)`；字体栈对齐蓝图（去 Inter 优先，系统栈）；焦点环改实色 accent 3px offset 3。语义色 ok/warn/fail/queue 不动。
2. **页头与标题**: `.eyebrow` 改 accent 色 12px/650/0.1em；`.view-h`/`.home-title` 650 字重 + -0.025em 字距。
3. **侧栏**: 选中态改回 **accent-soft 底 + accent-strong 字**（蓝图 nav 形态，两行条目结构保留）；阶段导航项加 mono 编号 01–05（蓝图 rail 编号位）；hover 统一 accent-soft；底部声明 strong 用正文色 650。
4. **按钮**: `.btn:hover` 改 accent 描边 + accent-soft 底；primary 仍为实心 accent（换新值）。
5. **Inspector 页签改分段控件**: `.insp-tabs` 容器 soft 底 padding 4 radius 9，活动段白底+描边+600（蓝图 `.segment` 形态，类名不动）。
6. **深藏青原则横条**: 新增 `.focusbar` 样式 + 在 **ExportView** 落地一处——主文案「有据、不越界、可检查」+ 白描边 chips（G1 内容批准 / G2 发布确认 / 外发单独授权 / 本机边界）+ small 注「并不等于让用户逐个批准每步」（与 agent-division 原则同构，文案源自蓝图）。
7. **新项目默认品牌**（`src/schema/brand.ts`）: primary→`#b44626`、accent→`#8f3820`，与 UI accent 同源（仅影响新建项目导出默认，Prism 主题结构不动）。

**冲突明示**: accent 从全局契约的 `#e8643a` 换成蓝图 `#b44626`，偏离 `~/.zcode/design/DESIGN.md` token 表——按你的指令「以这个版本为准」执行，全局规范留待你后续裁决。

**明确不做**: 蓝图的 stats 行、valuechain 四联条、layer 左轨卡网格（文档信息架构，与工作台不同构）；导出报告 Prism 主题不重构。
